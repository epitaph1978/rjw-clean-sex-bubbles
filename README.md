# [Epis] RJW Clean Sex Bubbles & Logs

**Authors:** Epitaph & Gemini 3.8 Flash  
**Compatibility:** RimWorld 1.5, 1.6, 1.7  
**Distribution:** Designed for Libidinous Loader and manual installation.

---

## 📖 Description

Removes redundant second sentences from RJW sex interaction logs and speech bubbles (Interaction Bubbles).

RJW interactions define both a specific r_logentry ('Orally serviced Asuka' / 'Was fucked vaginally by Ezekiel') and generic extraSentencePacks ('Rex had sex with Asuka' / 'Asuka was fucked vaginally by Ezekiel'). RimWorld concatenates both into one long, repetitive speech bubble.

This mod silences the generic second sentence so only the informative, specific action is shown.

---

## 📦 Installation

1. Download or clone this repository.
2. Place the folder into your `RimWorld/Mods/` directory.
3. Activate the mod in RimWorld's Mod Manager (or auto-install with Libidinous Loader).
